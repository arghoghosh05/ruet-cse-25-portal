# RUET CSE '25 Portal 🎓

A dedicated web platform designed for the students of the Computer Science & Engineering department (25 series) at Rajshahi University of Engineering & Technology (RUET).

---

## 📌 Features
- 📚 **Academic Resources:** Direct access to course syllabi, lecture slides, and notes.
- 📅 **Schedules & Notices:** Central hub for class routines, exam timetables, and department updates.
- 🔗 **Useful Links:** Quick access to university portals, faculty contacts, and reference materials.
- 📱 **Responsive UI:** Clean interface optimized for both desktop and mobile screens.

---

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
